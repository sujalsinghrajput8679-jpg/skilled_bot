🏋️‍♂️ Fitness & Diet Planner Bot

A smart, interactive chatbot built to help users plan workouts, track fitness goals, and get customized diet suggestions. Designed for use on IBM Cloud Watson Assistant.

🚀 Features

* Personalized workout recommendations
* Diet plans based on user goals (weight loss, muscle gain, maintenance)
* Meal suggestions & nutrient guidance
* Easy chatbot interaction using IBM Watson Assistant

📂 Project Structure
fitness-diet-bot/
│

│   ├── diet_plans.json

│   └── goodbye.json
│
├── entities/
│   ├── fitness_goals.json
│   ├── food_types.json
│   └── exercise_types.json
│
└── README.md

🔧 How It Works

1. User enters their goal → bot identifies it through intents & entities
2. Bot generates a personalized workout or diet plan
3. Bot gives healthy tips & daily guidelines

🧠 Technologies Used

* IBM Cloud Watson Assistant
* JSON (intents, entities, responses)
* Optional: IBM Cloud Functions for dynamic data

📌 Example Queries

* “Suggest a workout for weight loss”
* “Give me a vegetarian diet plan”
* “What should I eat after workout?”

Future Enhancements

* Integration with wearable devices
* Daily calorie tracker
* Personalized weekly fitness reports
